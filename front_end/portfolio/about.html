Acerca de mí

¿Como nace GrayDev?

2016-2019

A mis 15 años comencé a programar en el CBTis #30 en Cerro Azul, Veracruz; utilizando C++ y Java.
Unos semestres más tarde aprendí a desarrollar aplicaciones web muy básicas con HTML y CSS, también aprendí Android con Java de forma muy básica, aunque en ese momento ya no se utilizaba Java para Android.

2021-2023

En 2020 comencé a a estudiar en la UNITEC Campus Querétaro la carrera de Ingeniería en Sistemas Computacionales, pero no fue hasta 2021 en la cual estudié C++ avanzado, Java básico, Python básico, PHP, HTML y CSS.
A finales de año me di cuenta de lo mucho que me gustaba desarrollar sobre todo en web, así que comencé a estudiar de forma autodidacta. Empecé con el curso de Python desde cero de MoureDev en YouTube en ese momento, pero aún no desarrollaba proyectos.

2024

A inicios de año empecé a investigar como podía dedicarme profesionalmente a esto. Así que empecé a estudiar control de versiones (Git), aprendí a usar repos de GitHub, y entré a Python avanzado dominando un framework actualmente (FastAPI).
En estos momentos sigo estudiando Python y aprendiendo Django, también estoy tomando un curso de Academia Hola Mundo de JavaScript y React.

Actualmente tengo 23 años y no me estoy dedicando a esto de forma profesional, pero sigo desarrollando proyectos que puedan elevar mi status como desarrollador web. Tengo muchas ganas de que me conozcan y trabajar en proyectos que puedan ayudar a la sociedad.

Si tienes un proyecto en mente, no dudes en contactarme. ¡Estoy seguro de que puedo ayudarte!
